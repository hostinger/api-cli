## hostinger hosting domains list-website-parked

List website parked domains

### Synopsis

Retrieve all parked or alias domains created under the selected website.

Use this endpoint to inspect parked domain configuration for a specific website,
including the parent domain and root directory assigned to each parked domain.

The website can be given as [domain] (the account username is looked up), as <username> <domain>, or left out, in which case it comes from --domain, HOSTINGER_DOMAIN, the .hostinger/site.json written by `hostinger up` or `hostinger link`, the default_domain in the config file, or a prompt when run in a terminal.

```
hostinger hosting domains list-website-parked [domain] [flags]
```

### Examples

```
  hostinger hosting domains list-website-parked mydomain.tld
```
