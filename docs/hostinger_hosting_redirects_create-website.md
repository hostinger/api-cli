## hostinger hosting redirects create-website

Create website redirect

### Synopsis

Creates a redirect from a URL on the selected website to another URL or IP address.

The website can be given as [domain] (the account username is looked up), as <username> <domain>, or left out, in which case it comes from --domain, HOSTINGER_DOMAIN, the .hostinger/site.json written by `hostinger up` or `hostinger link`, the default_domain in the config file, or a prompt when run in a terminal.

```
hostinger hosting redirects create-website [domain] [flags]
```

### Examples

```
  hostinger hosting redirects create-website mydomain.tld --from https://example.com/old-page --to https://example.com/new-page
```

### Options

```
      --from string   Source URL on the selected website
  -h, --help          help for create-website
      --to string     Destination URL or IP address
```
