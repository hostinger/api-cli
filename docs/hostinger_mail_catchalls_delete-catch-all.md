## hostinger mail catchalls delete-catch-all

Delete catch-all

### Synopsis

Delete a catch-all. Messages sent to unknown addresses of the domain
are no longer routed to the mailbox.

```
hostinger mail catchalls delete-catch-all <catchall-id> [flags]
```
