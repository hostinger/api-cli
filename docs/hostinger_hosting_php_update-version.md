## hostinger hosting php update-version

Update PHP version

### Synopsis

Changes the PHP version of the website.

Use the Get PHP details endpoint to see the versions available for the website.

The website can be given as [domain] (the account username is looked up), as <username> <domain>, or left out, in which case it comes from --domain, HOSTINGER_DOMAIN, the .hostinger/site.json written by `hostinger up` or `hostinger link`, the default_domain in the config file, or a prompt when run in a terminal.

```
hostinger hosting php update-version [domain] [flags]
```

### Examples

```
  hostinger hosting php update-version mydomain.tld --version 8.1
```

### Options

```
  -h, --help             help for update-version
      --version string   PHP version to switch the website to.
```
