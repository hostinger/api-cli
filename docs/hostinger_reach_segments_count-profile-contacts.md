## hostinger reach segments count-profile-contacts

Count profile segment contacts

### Synopsis

Count the contacts currently matching a segment without listing them.

Cheaper than paging through the segment contacts endpoint when only the size is needed.

```
hostinger reach segments count-profile-contacts <profile-uuid> <segment-uuid> [flags]
```

### Examples

```
  hostinger reach segments count-profile-contacts 550e8400-e09b-41d4-a716-400055000000 550e8400-e09b-41d4-a716-400055000000
```
